# LLM P2（全量向量化 + 混合语义搜索）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为全部本地 memo 建立向量索引（用户自配 embedding 端点、后台分批、断点续传、可暂停/清除），并把搜索升级为"关键词 LIKE ∪ 向量 top-k"混合检索；同时吸收 P1 最终评审的推迟加固项。

**Architecture:** 复用 P1 的 LLM 客户端层（`LlmApi.embeddings` + `LlmSettings`）。新增 drift 表 `MemoEmbeddings`（schema v1→v2），独立 `EmbeddingDao`；向量化引擎订阅 `watchAll` 语料流（防抖触发，不改动 `sync_engine.dart`），单飞、批量 16 条、失败停摆记录、暂停/恢复/清除。向量检索为 Dart 内存余弦（`Isolate.run` 计算 top-k），搜索页在关键词结果之上叠加"语义相关"横滑区。语料与向量一律按 `accountId` 隔离。

**Tech Stack:** Flutter 3.47+ / Dart 3.13+、drift（schema v2 + `dart run build_runner build`）、flutter_riverpod、dio/http_mock_adapter、shared_preferences。

新建 `lib/core/utils/stable_hash.dart`：

```dart
/// FNV-1a 变体哈希（32 位，掩码到 31 位正整数），跨进程/重启稳定——
/// 不同于 `Object.hashCode`（每次运行可能不同）。用于缓存指纹与
/// 内容变更检测这类需要持久一致性的场景。
int stableHash(String input) {
  var hash = 0x811c9dc5;
  for (final code in input.codeUnits) {
    hash ^= code;
    hash = (hash * 0x01000193) & 0x7FFFFFFF;
  }
  return hash;
}
```

```dart
import '../api/llm_api.dart';

/// Maps an LLM-layer error to a localized, user-facing message: transport
/// classes get dedicated copy, everything else falls back to the API
/// message (which already carries the HTTP status) or `toString()`.
String llmErrorMessage(AppLocalizations l10n, Object error) {
  final api = asLlmApiError(error);
  if (api == null) return error.toString();
  return switch (api.kind) {
    LlmErrorKind.timeout => l10n.llmErrTimeout,
    LlmErrorKind.unreachable => l10n.llmErrUnreachable,
    LlmErrorKind.auth => l10n.llmErrAuth,
    _ => api.message,
  };
}
```

```dart
/// Coarse error class so UI can localize without parsing messages.
enum LlmErrorKind { timeout, unreachable, auth, http, unknown }

/// Typed error surfaced by the LLM layer so UI can show friendly messages.
class LlmApiException implements Exception {
  const LlmApiException(this.message,
      {this.statusCode, this.cause, this.kind = LlmErrorKind.unknown});

  final String message;
  final int? statusCode;
  final Object? cause;
  final LlmErrorKind kind;

  @override
  String toString() => 'LlmApiException($statusCode): $message';
}

/// Coarse class of a transport failure: timeouts, unreachable hosts and
/// auth rejections get dedicated localized copy in the UI.
LlmErrorKind _kindOf(DioException e) {
  final status = e.response?.statusCode;
  if (status == 401 || status == 403) return LlmErrorKind.auth;
  if (status != null) return LlmErrorKind.http;
  return switch (e.type) {
    DioExceptionType.connectionTimeout ||
    DioExceptionType.sendTimeout ||
    DioExceptionType.receiveTimeout =>
      LlmErrorKind.timeout,
    DioExceptionType.connectionError => LlmErrorKind.unreachable,
    _ => LlmErrorKind.unknown,
  };
}
```

```dart

      final list = data['data'];
      if (list is! List) return const [];
      // OpenAI 兼容服务按 index 对齐向量与输入；缺 index 时退回出现顺序
      // （ordinal），坏项（非 Map / 非 List embedding）直接跳过。
      final entries = <(int, List<double>)>[];
      var ordinal = 0;
      for (final item in list) {
        final order = ordinal++;
        if (item is! Map) continue;
        final raw = item['embedding'];
        if (raw is! List) continue;
        final index = item['index'];
        entries.add((
          index is int ? index : order,
          raw.whereType<num>().map((n) => n.toDouble()).toList(),
        ));
      }
      entries.sort((a, b) => a.$1.compareTo(b.$1));
      return [for (final e in entries) e.$2];
```

3. `ReviewDigestCache` 整体替换为：

```dart
/// Daily digest cache in shared preferences, one key per account + local
/// day; only the newest 7 day keys of the active account are kept so the
/// cache cannot grow unboundedly (corpus is accountId-isolated by design).
class ReviewDigestCache {
  static const _prefix = 'memos_go.reviewDigest.';

  String _key(String accountId, String dayKey) =>
      '$_prefix$accountId.$dayKey';

  Future<ReviewDigestEntry?> load(String accountId, String dayKey) async {
    final prefs = await SharedPreferences.getInstance();
    final raw = prefs.getString(_key(accountId, dayKey));
```

```dart
import 'dart:typed_data';

import 'package:drift/drift.dart';

import '../models/models.dart';
import 'app_database.dart';

part 'embedding_dao.g.dart';

/// A memo eligible for vectorization: uid + raw content.
class EmbeddableMemo {
  const EmbeddableMemo({required this.uid, required this.content});

  final String uid;
  final String content;
}

/// One vector to persist for a memo.
class EmbeddingWrite {
  const EmbeddingWrite(
      {required this.uid, required this.contentHash, required this.vector});

  final String uid;
  final int contentHash;
  final Float32List vector;
}

/// A stored vector blob for similarity search.
class VectorRow {
  const VectorRow({required this.uid, required this.bytes});

  final String uid;
  final Uint8List bytes;
}

/// All local-database access for the memo embedding index. Every query is
/// scoped by [accountId], mirroring [MemoDao]'s convention.
@DriftAccessor(tables: [MemoEmbeddings, Memos])
class EmbeddingDao extends DatabaseAccessor<AppDatabase>
    with _$EmbeddingDaoMixin {
  EmbeddingDao(super.db);

  /// The vectorization corpus: normal memos with non-empty content.
  Future<List<EmbeddableMemo>> corpus(String accountId) async {
    final rows = await (selectOnly(memos)
          ..addColumns([memos.uid, memos.content])
          ..where(memos.accountId.equals(accountId) &
              memos.state.equals(MemoState.normal.wireName) &
              memos.content.equals('').not()))
        .get();
    return [
      for (final row in rows)
        EmbeddableMemo(
            uid: row.read(memos.uid)!,
            content: row.read(memos.content)!),
    ];
  }

  /// uid -> contentHash for rows already embedded with [model].
  Future<Map<String, int>> embeddedHashes(String accountId, String model) async {
    final rows = await (selectOnly(memoEmbeddings)
          ..addColumns([memoEmbeddings.memoUid, memoEmbeddings.contentHash])
          ..where(memoEmbeddings.accountId.equals(accountId) &
              memoEmbeddings.model.equals(model)))
        .get();
    return {
      for (final row in rows)
        row.read(memoEmbeddings.memoUid)!:
            row.read(memoEmbeddings.contentHash)!,
    };
  }

  /// Inserts or replaces the given vectors (PK `(accountId, memoUid)`).
  Future<void> upsertAll(
      String accountId, String model, List<EmbeddingWrite> rows) {
    final now = DateTime.now();
    return batch((b) => b.insertAll(
          memoEmbeddings,
          [
            for (final row in rows)
              MemoEmbeddingsCompanion.insert(
                accountId: accountId,
                memoUid: row.uid,
                model: model,
                contentHash: row.contentHash,
                vector: Value(row.vector.buffer
                    .asUint8List(row.vector.offsetInBytes, row.vector.lengthInBytes)),
                embeddedAt: Value(now),
              ),
          ],
          mode: InsertMode.insertOrReplace,
        ));
  }

  /// All stored vectors for one model (the brute-force search input).
  Future<List<VectorRow>> vectorsForModel(String accountId, String model) async {
    final rows = await (selectOnly(memoEmbeddings)
          ..addColumns([memoEmbeddings.memoUid, memoEmbeddings.vector])
          ..where(memoEmbeddings.accountId.equals(accountId) &
              memoEmbeddings.model.equals(model)))
        .get();
    return [
      for (final row in rows)
        VectorRow(
            uid: row.read(memoEmbeddings.memoUid)!,
            bytes: row.read(memoEmbeddings.vector)!),
    ];
  }

  /// Drops embedding rows whose memo no longer exists (server-deleted).
  Future<void> deleteOrphans(String accountId) async {
    final remaining = selectOnly(memos)
      ..addColumns([memos.uid])
      ..where(memos.accountId.equals(accountId));
    await (delete(memoEmbeddings)
          ..where((e) =>
              e.accountId.equals(accountId) &
              e.memoUid.isNotInQuery(remaining)))
        .go();
  }

  Future<void> deleteAllForAccount(String accountId) =>
      (delete(memoEmbeddings)
            ..where((e) => e.accountId.equals(accountId)))
          .go();
}
```

```dart
enum VectorStatus { idle, running, paused, error }

class VectorizationState {
  const VectorizationState({
    this.status = VectorStatus.idle,
    this.embedded = 0,
    this.total = 0,
    this.lastError,
  });

  final VectorStatus status;
  final int embedded;
  final int total;
  final String? lastError;

  double? get fraction =>
      total == 0 ? null : (embedded / total).clamp(0.0, 1.0);

  VectorizationState copyWith({
    VectorStatus? status,
    int? embedded,
    int? total,
    String? lastError,
    bool clearError = false,
  }) =>
      VectorizationState(
        status: status ?? this.status,
        embedded: embedded ?? this.embedded,
        total: total ?? this.total,
        lastError: clearError ? null : (lastError ?? this.lastError),
      );
}

/// Incrementally embeds the account's corpus against the configured
/// OpenAI-compatible endpoint. The embedding table itself is the resume
/// state: a pass embeds whatever's missing or hash-stale in batches of
/// [batchSize], so interruptions (app kill, pause, error) lose nothing.
/// Errors stop the pass instead of retry-storming; the next trigger (a
/// corpus change via watchAll, a settings save, or resume) retries.
class VectorizationEngine {
  VectorizationEngine({
    required this.accountId,
    required AppDatabase db,
    required LlmRepository repository,
  })  : _dao = db.embeddingDao,
        _memoDao = db.memoDao,
        _repository = repository;

  static const batchSize = 16;

  final String accountId;
  final EmbeddingDao _dao;
  final MemoDao _memoDao;
  final LlmRepository _repository;

  final state = ValueNotifier<VectorizationState>(const VectorizationState());

  bool _running = false;
  bool _paused = false;
  Timer? _debounce;
  StreamSubscription<void>? _corpusSub;

  /// Subscribes to corpus changes (any memo write lands there after sync)
  /// and kicks off an initial pass. Tests that call [run] directly skip
  /// this to stay timer-free.
  void start() {
    _corpusSub = _watchCorpus().listen((_) => schedule());
    schedule();
  }

  Stream<void> _watchCorpus() =>
      _memoDao.watchAll(accountId).map<void>((_) {});

  /// Debounced pass request, e.g. after a sync wrote new memos.
  void schedule({Duration delay = const Duration(seconds: 4)}) {
    _debounce?.cancel();
    _debounce = Timer(delay, run);
  }

  /// Runs one pass. Never throws; failures land in [state].
  Future<void> run() async {
    if (_running || _paused) return;
    _running = true;
    try {
      final settings = await _repository.load();
      final model = settings.embeddingModel.trim();
      if (!settings.embeddingsConfigured) {
        _state(const VectorizationState());
        return;
      }

      final corpus = await _dao.corpus(accountId);
      final hashes = await _dao.embeddedHashes(accountId, model);
      final pending = <EmbeddableMemo>[
        for (final m in corpus)
          if (hashes[m.uid] != stableHash(m.content)) m
      ];
      var done = corpus.length - pending.length;
      _state(VectorizationState(
          status: VectorStatus.running,
          embedded: done,
          total: corpus.length));

      for (var i = 0; i < pending.length; i += batchSize) {
        if (_paused) return;
        final batch = pending.skip(i).take(batchSize).toList();
        try {
          final vectors = await _repository.embeddings(
              settings,
              inputs: [for (final m in batch) m.content]);
          if (vectors.length != batch.length) {
            throw LlmApiException(
                'Embedding count mismatch: ${vectors.length} of ${batch.length}');
          }
          await _dao.upsertAll(accountId, model, [
            for (var j = 0; j < batch.length; j++)
              EmbeddingWrite(
                  uid: batch[j].uid,
                  contentHash: stableHash(batch[j].content),
                  vector: Float32List.fromList(vectors[j])),
          ]);
        } on LlmApiException catch (e) {
          _state(state.value.copyWith(
              status: VectorStatus.error, lastError: e.message));
          return;
        } catch (e) {
          _state(state.value.copyWith(
              status: VectorStatus.error, lastError: e.toString()));
          return;
        }
        done += batch.length;
        _state(state.value.copyWith(embedded: done));
      }

      await _dao.deleteOrphans(accountId);
      // A completed pass makes the current model the only source of truth;
      // rows of previously used models are dead weight (the 3-column PK
      // keeps them around otherwise).
      await _dao.deleteOtherModels(accountId, model);
      _state(VectorizationState(
          status: VectorStatus.idle,
          embedded: corpus.length,
          total: corpus.length));
    } finally {
      _running = false;
    }
  }

  void pause() {
    _paused = true;
    _debounce?.cancel();
    _state(state.value.copyWith(status: VectorStatus.paused));
  }

  void resume() {
    _paused = false;
    _state(state.value.copyWith(
        status: VectorStatus.running, clearError: true));
    schedule(delay: Duration.zero);
  }

  /// Wipes the account's vectors and resets progress. A fresh pass needs a
  /// new trigger (settings save, corpus change, or resume).
  Future<void> clearVectors() async {
    _debounce?.cancel();
    await _dao.deleteAllForAccount(accountId);
    _state(const VectorizationState());
  }

  Future<void> dispose() async {
    _debounce?.cancel();
    await _corpusSub?.cancel();
  }

  void _state(VectorizationState next) => state.value = next;
}
```

```dart
import 'dart:isolate';
import 'dart:math' as math;
import 'dart:typed_data';

/// Decodes a little-endian float32 blob into a vector.
Float32List decodeVector(Uint8List bytes) {
  final out = Float32List(bytes.length ~/ 4);
  final view = ByteData.view(bytes.buffer, bytes.offsetInBytes, bytes.length);
  for (var i = 0; i < out.length; i++) {
    out[i] = view.getFloat32(i * 4, Endian.little);
  }
  return out;
}

/// Encodes a vector as little-endian float32 bytes for the blob column.
Uint8List encodeVector(List<double> vector) {
  final view = ByteData(vector.length * 4);
  for (var i = 0; i < vector.length; i++) {
    view.setFloat32(i * 4, vector[i], Endian.little);
  }
  return view.buffer.asUint8List();
}

/// Cosine similarity; zero vectors and length mismatches yield 0.
double cosineSimilarity(Float32List a, Float32List b) {
  if (a.isEmpty || a.length != b.length) return 0;
  var dot = 0.0, na = 0.0, nb = 0.0;
  for (var i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    na += a[i] * a[i];
    nb += b[i] * b[i];
  }
  if (na == 0 || nb == 0) return 0;
  return dot / (math.sqrt(na) * math.sqrt(nb));
}

class ScoredUid {
  const ScoredUid(this.uid, this.score);

  final String uid;
  final double score;
}

/// Brute-force cosine top-k over the stored vectors, computed in a
/// background isolate (personal-scale corpora: a few thousand × 1024-dim
/// scans take single-digit milliseconds but would jank the UI thread).
Future<List<ScoredUid>> topKSimilar(
    Float32List query, Map<String, Uint8List> vectors, int k) {
  return Isolate.run(() {
    final scored = <ScoredUid>[
      for (final entry in vectors.entries)
        ScoredUid(entry.key, cosineSimilarity(query, decodeVector(entry.value)))
    ];
    scored.sort((a, b) => b.score.compareTo(a.score));
    return scored.take(k).toList();
  });
}
```

```dart
import 'dart:typed_data';

import 'package:flutter_riverpod/flutter_riverpod.dart';

import '../core/utils/vector_math.dart';
import '../data/local/memo_dao.dart' show MemoRecord;
import '../data/repositories/llm_repository.dart';
import 'auth_providers.dart';
import 'llm_providers.dart';
import 'sync_providers.dart' show appDatabaseProvider;

/// Semantic top-12 for a query, ranked by cosine similarity against the
/// account's stored vectors. Degrades to an empty list when the LLM layer
/// is unconfigured, has no embedding model, holds no vectors, or the
/// endpoint fails — keyword search never breaks because of it.
final semanticSearchProvider =
    FutureProvider.autoDispose.family<List<MemoRecord>, String>(
        (ref, query) async {
  final trimmed = query.trim();
  if (trimmed.isEmpty) return const [];

  final account = ref.watch(authProvider).activeAccount;
  if (account == null) return const [];

  final repo = ref.watch(llmRepositoryProvider);
  final settings = await repo.load();
  if (!settings.embeddingsConfigured) return const [];

  final db = ref.watch(appDatabaseProvider);
  final model = settings.embeddingModel.trim();
  final vectors = await db.embeddingDao.vectorsForModel(account.id, model);
  if (vectors.isEmpty) return const [];

  final List<List<double>> queryVectors;
  try {
    queryVectors = await repo.embeddings(settings, inputs: [trimmed]);
  } catch (_) {
    return const [];
  }
  if (queryVectors.isEmpty || queryVectors.first.isEmpty) return const [];

  final top = await topKSimilar(
      Float32List.fromList(queryVectors.first),
      {for (final row in vectors) row.uid: row.bytes},
      12);
  return db.memoDao.recordsByUids(
      account.id, [for (final scored in top) scored.uid]);
});
```

```dart
import 'dart:async';

import 'package:flutter/material.dart';
import '../../l10n/generated/app_localizations.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';

import '../../data/local/memo_dao.dart' show MemoRecord;

class SearchPage extends ConsumerStatefulWidget {
  const SearchPage({super.key});

  @override
  ConsumerState<SearchPage> createState() => _SearchPageState();
}

class _SearchPageState extends ConsumerState<SearchPage> {
  String _query = '';
  String _semanticQuery = '';
  Timer? _semanticDebounce;

  @override
  void dispose() {
    _semanticDebounce?.cancel();
    super.dispose();
  }

  /// The semantic provider is a per-string autoDispose family that pays a
  /// keychain read, a full vector scan and one embeddings call per key —
  /// debounce the key so typing doesn't fan out into per-keystroke calls.
  void _onQueryChanged(String value) {
    setState(() => _query = value);
    _semanticDebounce?.cancel();
    _semanticDebounce = Timer(const Duration(milliseconds: 400), () {
      if (mounted) setState(() => _semanticQuery = value.trim());
    });
  }

  @override
  Widget build(BuildContext context) {
    final l10n = AppLocalizations.of(context)!;
    final theme = Theme.of(context);
    final trimmed = _query.trim();
    final query = MemosQuery(search: trimmed.isEmpty ? null : trimmed);
    final list = ref.watch(memosListProvider(query));
    final repo = ref.watch(memoRepositoryProvider);
    // Hybrid search: keyword hits stay the primary feed; semantic hits add
    // a related-memos rail on top when the LLM layer has vectors.
    final semantic = _semanticQuery.isEmpty
        ? const <MemoRecord>[]
        : ref.watch(semanticSearchProvider(_semanticQuery)).value ?? const <MemoRecord>[];

    return Scaffold(
      appBar: AppBar(title: Text(l10n.searchTitle)),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.fromLTRB(14, 4, 14, 8),
            child: SearchBar(
              leading: const Icon(Icons.search),
              hintText: l10n.searchHint,
              onChanged: _onQueryChanged,
            ),
          ),
          if (semantic.isNotEmpty && repo != null)
            SizedBox(
              height: 170,
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Padding(
                    padding: const EdgeInsets.fromLTRB(14, 0, 14, 6),
                    child: Row(children: [
                      Icon(Icons.auto_awesome_outlined,
                          size: 16, color: theme.colorScheme.primary),
                      const SizedBox(width: 6),
                      Text(l10n.searchSemantic,
                          style: theme.textTheme.titleSmall
                              ?.copyWith(fontWeight: FontWeight.w700)),
                    ]),
                  ),
                  Expanded(
                    child: ListView.builder(
                      scrollDirection: Axis.horizontal,
                      padding: const EdgeInsets.symmetric(horizontal: 12),
                      itemCount: semantic.length,
                      itemBuilder: (context, index) => SizedBox(
                        width: 280,
                        child: Padding(
```
