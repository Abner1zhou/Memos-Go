# LLM P4（保存时建议）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** memo 保存后静默生成"≤3 个建议标签 + ≤3 条相关记忆"，在详情页底部呈现（标签 chip 点击即加、相关记忆点击跳转），结果按 memo 缓存、内容变更失效重算、设置页可整体关闭；同时吸收历期评审的推迟加固项。

**Architecture:** 复用 `RetrievalService`（P2/P3 的共享检索）。新增 drift 表 `MemoSuggestions`（schema v3→v4，按 contentHash 失效）；`SuggestionEngine` 订阅语料流做**差异快照**（首帧只建快照不回填，其后新增/变更的 memo 入队防抖处理：取账号标签清单 + 向量候选 → 一次非流式 chat 要求严格 JSON → 防御解析与候选校验 → 落库）。详情页新增 `MemoSuggestionSection`（响应式 watch 建议行；打标签 = 内容追加 `#tag` 走仓库更新）。两个前置任务落地历期评审加固（字符安全截断、引用定义掩码、SocketException 分类、chat UI 打磨与死代码）。

**Tech Stack:** Flutter 3.47+ / Dart 3.13+、drift（schema v4 + build_runner）、flutter_riverpod、dio、package:characters（Flutter 自带）。

## Global Constraints

- 依赖方向：features → providers → data（api/local/llm）；UI 不直接调 dio。
- 所有建议表查询带 `accountId`；memo 删除/sweep/账号清除连带清理建议行；建议数据不参与服务端同步。
- drift schema 升到 **4**：`onUpgrade` 为 from < 4 建 `memo_suggestions` 表；跑 `dart run build_runner build` 并提交生成文件（注意：该 flag 在当前 build_runner 已是无效旗标，可省略）。
- i18n：模板中文（`app_zh.arb`），英文 `app_en.arb`；`flutter gen-l10n` 后提交生成物。
- 护栏（spec §7）：≤3 标签（优先复用已有标签）、≤3 相关（uid 必须来自检索候选且非自身）、静默失败（不阻塞、不弹错）、结果按 memo 缓存（contentHash 失效重算）、设置可整体关闭（`LlmSettings.suggestOnSave`，默认开启）。
- 提交信息 conventional commits；worktree 分支 `claude/llm-p4-suggest`（已基于 origin/main 2d7c3db 创建）。
- **推送 GitHub 优先直连**（`git push`），失败再带代理 `git -c http.proxy=http://127.0.0.1:7897 push`——最近代理间歇性 SSL 失联而直连可用；gh 命令同理（先直连后 `https_proxy=...`）。

```dart
import 'package:characters/characters.dart';

/// Clips [text] to at most [maxChars] grapheme clusters (emoji- and
/// CJK-safe, unlike String.substring's UTF-16 units), trimming ends and
/// appending an ellipsis when clipped. Shared budget helper for prompts,
/// cache titles and excerpts.
String clipText(String text, int maxChars) {
  final trimmed = text.trim();
  if (trimmed.characters.length <= maxChars) return trimmed;
  return '${trimmed.characters.take(maxChars).toString()}…';
}
```

  void _scheduleAutoScroll() {
    WidgetsBinding.instance.addPostFrameCallback((_) {
      if (!mounted || !_scroll.hasClients) return;
      final max = _scroll.position.maxScrollExtent;
      final distance = max - _scroll.position.pixels;
      final away = distance > _scroll.position.viewportDimension;
      if (away) return; // 用户主动上翻浏览历史时不打扰
      _scroll.animateTo(max,
          duration: const Duration(milliseconds: 120), curve: Curves.easeOut);
    });
  }

  final List<String> relatedUids;

String suggestionToJson(MemoSuggestion s) => convert.jsonEncode({
      'tags': s.tags,
      'related': s.relatedUids,
    });

MemoSuggestion? suggestionFromJson(String raw) {
  try {
    final json = convert.jsonDecode(raw);
    if (json is! Map) return null;
    return MemoSuggestion(
      tags: [
        for (final t in (json['tags'] is List ? json['tags'] as List : const []))
          if (t is String) t
      ],
      relatedUids: [
        for (final r
            in (json['related'] is List ? json['related'] as List : const []))
          if (r is String) r
      ],
    );
  } catch (_) {
    return null;
  }
}

extension MemoSuggestionsRowParsed on MemoSuggestionsRow {
  List<String> get tagList => _stringList(tagsJson);
  List<String> get relatedUidList => _stringList(relatedUidsJson);
}

List<String> _stringList(String raw) {
  try {
    final json = convert.jsonDecode(raw);
    if (json is! List) return const [];
    return [for (final e in json) if (e is String) e];
  } catch (_) {
    return const [];
  }
}

          relatedUidsJson: Value(suggestion.relatedUids.isEmpty
              ? '[]'
              : convert.jsonEncode(suggestion.relatedUids)),
          createdAt: Value(now),
        ),
      );

      ..addColumns([memoTags.tag])
      ..where(memoTags.accountId.equals(accountId))
      ..groupBy([memoTags.tag])
      ..orderBy([OrderingTerm.asc(memoTags.tag)]);

    return [for (final row in rows) row.read(memoTags.tag)!];

      (delete(memoSuggestions)
            ..where((s) =>
                s.accountId.equals(accountId) & s.memoUid.equals(memoUid)))
          .go();

import 'package:flutter/foundation.dart';

import '../../core/utils/stable_hash.dart';

import '../api/llm_api.dart';

/// Parses the model's suggestion output: strips ```json fences, extracts
/// the first balanced {...} block, then validates against the retrieval
/// candidates. Tags: ≤3, deduped, '#' stripped, non-empty, clipped to 24
/// chars. Related: ≤3, must reference a candidate (by 1-based number or
/// full name), self excluded, deduped, order preserved. Returns null on
/// any malformed output.
MemoSuggestion? parseSuggestion(String raw,
    {required List<String> candidateUids, required String selfName}) {
  var text = raw.trim();
  final fence = RegExp(r'```(?:json)?\s*([\s\S]*?)```');
  final m = fence.firstMatch(text);
  if (m != null) text = m.group(1)!.trim();
  final start = text.indexOf('{');
  if (start < 0) return null;
  var depth = 0;
  var end = -1;
  for (var i = start; i < text.length; i++) {
    final ch = text[i];
    if (ch == '{') depth++;
    if (ch == '}') {
      depth--;
      if (depth == 0) {
        end = i;
        break;
      }
    }
  }
  if (end < 0) return null;
  final json = _decodeJson(text.substring(start, end + 1));
  if (json is! Map) return null;

  final tags = <String>[];
  final rawTags = json['tags'];
  if (rawTags is List) {
    for (final t in rawTags) {
      if (t is! String) continue;
      final tag = clipText(t.trim().replaceFirst(RegExp('^#+'), ''), 24);
      if (tag.isEmpty || tags.contains(tag) || tags.length >= 3) continue;
      tags.add(tag);
    }
  }

  final byNumber = {for (var i = 0; i < candidateUids.length; i++) i + 1: candidateUids[i]};
  final related = <String>[];
  final rawRelated = json['related'];
  if (rawRelated is List) {
    for (final r in rawRelated) {
      String? name;
      if (r is int) name = byNumber[r];
      if (r is String && candidateUids.contains(r)) name = r;
      if (name == null || name == selfName || related.contains(name)) continue;
      if (related.length >= 3) break;
      related.add(name);
    }
  }
  return MemoSuggestion(tags: tags, relatedUids: related);
}

/// Save-time suggestions per spec §7: watches the corpus stream with a
/// uid→contentHash snapshot; the FIRST emission only seeds the snapshot
/// (no backfill of the existing corpus), later new/changed memos are
/// queued, debounced, and each gets one retrieval + one JSON completion.
/// Failures are silent (lastError), never blocking, never retried.
class SuggestionEngine {
  SuggestionEngine({
    required this.accountId,
    required AppDatabase db,
    required LlmRepository repository,
    required RetrievalService retrieval,
  })  : _db = db,
        _repository = repository,
        _retrieval = retrieval;

  static const debounce = Duration(seconds: 5);
  static const candidateCount = 6;
  static const excerptChars = 400;

  final String accountId;
  final AppDatabase _db;
  final LlmRepository _repository;
  final RetrievalService _retrieval;

  final lastError = ValueNotifier<String?>(null);

  final Map<String, int> _snapshot = {};
  final Set<String> _pending = {};
  bool _seeded = false;
  bool _running = false;
  Timer? _timer;
  StreamSubscription<List<MemoRecord>>? _corpusSub;

  void start() {
    _corpusSub = _db.memoDao.watchAll(accountId).listen(_onCorpus);
  }

  void _onCorpus(List<MemoRecord> records) {
    final next = <String, int>{
      for (final r in records) r.memo.uid: stableHash(r.memo.content),
    };
    if (!_seeded) {
      _seeded = true;
      _snapshot.addAll(next);
      return; // 首帧只建快照：存量语料不回填（spec：保存后触发）。
    }
    var changed = false;
    for (final uid in {..._snapshot.keys}..removeAll(next.keys)) {
      _snapshot.remove(uid);
      _pending.remove(uid);
      _db.suggestionDao.deleteForMemo(accountId, uid);
    }
    next.forEach((uid, hash) {
      if (_snapshot[uid] != hash) {
        _snapshot[uid] = hash;
        _pending.add(uid);
        changed = true;
      }
    });
    if (changed) _schedule();
  }

  void _schedule() {
    _timer?.cancel();
    _timer = Timer(debounce, run);
  }

  /// Runs one drain of the queue. Never throws.
  Future<void> run({String language = 'zh'}) async {
    if (_running) return;
    _running = true;
    try {
      final settings = await _repository.load();
      if (!settings.isConfigured ||
          !settings.suggestOnSave ||
          !settings.embeddingsConfigured) {
        _pending.clear();
        return;
      }
      while (_pending.isNotEmpty) {
        final uid = _pending.first;
        _pending.remove(uid);
        try {
          final record = await _db.memoDao.getMemo(accountId, uid);
          if (record == null) continue;
          final content = record.memo.content;
          final contentHash = stableHash(content);
          final existing =
              await _db.suggestionDao.watchSuggestion(accountId, uid).first;
          if (existing != null && existing.contentHash == contentHash) {
            continue;
          }

          var hits = await _retrieval.retrieve(accountId, content,
              k: candidateCount);
          hits = [
            for (final h in hits)
              if (h.record.memo.name != record.memo.name) h
          ];
          final candidateUids = [
            for (final h in hits) h.record.memo.name
          ];
          if (candidateUids.isEmpty) continue;

          final tags = await _db.suggestionDao.distinctTags(accountId);
          final answer = await _repository.chat(
            settings,
            messages: [
              LlmChatMessage(role: 'system', content: _systemPrompt(language)),
              LlmChatMessage(
                  role: 'user',
                  content: _userPrompt(
                      content,
                      tags,
                      [for (final h in hits) h.record],
                      language)),
            ],
            maxTokens: 256,
          );
          final suggestion = parseSuggestion(answer,
              candidateUids: candidateUids, selfName: record.memo.name);
          if (suggestion == null ||
              (suggestion.tags.isEmpty && suggestion.relatedUids.isEmpty)) {
            continue;
          }
          await _db.suggestionDao.upsert(
            accountId,
            uid,
            contentHash: contentHash,
            suggestion: suggestion,
            now: DateTime.now(),
          );
        } on LlmApiException catch (e) {
          lastError.value = e.message;
        } catch (e) {
          lastError.value = e.toString();
        }
      }
    } finally {
      _running = false;
    }
  }

  Future<void> dispose() async {
    _timer?.cancel();
    await _corpusSub?.cancel();
  }

  static String _systemPrompt(String language) => language == 'en'
      ? 'You suggest metadata for a just-saved note. Answer with JSON ONLY, '
        'no prose: {"tags": [up to 3 strings], "related": [up to 3 numbers]} '
        '-- tags prefer the listed existing tags; related picks the most '
        'relevant numbered candidates (or omit both arrays when nothing fits).'
      : '你为刚保存的笔记建议元数据。只输出 JSON，不要任何其他文字：'
        '{"tags": [最多 3 个字符串], "related": [最多 3 个编号]}'
        '——tags 优先从列出的已有标签中选；related 选最相关的编号候选；都不合适可为空数组。';

  static String _userPrompt(String content, List<String> tags,
      List<MemoRecord> records, String language) {
    final b = StringBuffer();
    b.writeln(language == 'en'
        ? 'Existing tags: ${tags.join(', ')}'
        : '已有标签：${tags.join('、')}');
    b.writeln();
    b.writeln(language == 'en' ? 'Candidate related memos:' : '候选相关记忆：');
    for (var i = 0; i < records.length; i++) {
      b.writeln('[${i + 1}] ${clipText(records[i].memo.content, excerptChars)}');
    }
    b.writeln();
    b.writeln(language == 'en' ? 'New note:' : '新笔记：');
    b.writeln(clipText(content, excerptChars));
    return b.toString();
  }
}
